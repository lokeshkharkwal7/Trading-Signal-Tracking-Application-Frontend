# Trading-Signal-Tracking-Application-Frontend

This repository contains the frontend assessment submitted by **Lokesh Kharkwal**.

The frontend is built using **React**.

## Setup

1. Install the project dependencies:
   ```bash
   npm install
   ```

2. Start the frontend development server:
   ```bash
   npm start
   ```

## Notes

- Please ensure the frontend is connected to the correct backend configuration.
- A demo video and the relevant GitHub links are shared separately for reference.
